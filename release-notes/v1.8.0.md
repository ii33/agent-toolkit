# 通用 agent 工具集 v1.8.0

`@local/dsh-agentkit` —— 与翻译、模型无关的通用 agent 工具集，以 DSH 的 bundle + agent preset 形式分发。

这一版的主题是**修「工具自己造的假现象」**：描述与实际不符、错误信息误导、默认值压制效率、观测逻辑污染被观测对象。

## 两个严重缺陷

**1. 工具注册的生命周期归位 —— 修「能删不能加」**

`ctx.tools.register()` 返回 disposer，但本插件把它直接 `return` 给 `apply()`，而各能力的
`apply` 从不接收返回值 —— **disposer 被丢弃**。这些注册因此永远留在 scope 层里：

- 关掉能力后工具还在（提示词里删了、实现还活着）
- 重新打开时撞上同一作用域的残留注册
- 旧会话会落到「52 个工具变成 39 个」这类半新半旧的混态
- 唯一解法是重建会话

现在注册器内部收集 disposer 并暴露 `disposeAll()`，`createToolRegistrar()` 默认登记到
`ctx.effect` —— 14 个能力的 `apply` 一行不用改，生命周期自动生效。逆序卸载、抛错隔离、
清理后允许重新注册同名工具。

**2. 委派组加回预设 —— 修 subagent 缺失**

1.7.0 为消除「scoped 遮蔽 global」的重复，把 delegation 组从预设里删掉，想依赖
`dsh-base` 的全局行提供 subagent。**实测：base 的全局行在预设作用域内并不真正提供这些工具。**

结果 11-12 00:47 之后创建的 generic 会话工具数 47→39，缺失
`subagent / subagent_fork / workflow / list_agents / wait_agent / interrupt_agent`，
连不用本工具集的 `standard` 预设也受影响。

现在 delegation 组恢复到预设内（`tool-subagent-control / tool-subagent / tool-subagent-fork /
workflow-ptc / tool-workflow`）。结论：重复注册的代价远小于功能缺失。

## 描述与错误信息不再误导

这几处都属于同一类问题：**工具说的话和实际不符**，而模型会照着做。

| 修了什么 | 之前 | 现在 |
|---|---|---|
| 能力清单措辞 | 「其余能力未启用，不要尝试」被读成工具全集，模型据此放弃委派 | 「仅描述本插件自己注册的工具；其它来源的工具照常可用」 |
| 纪律条款（新增） | 无 | 拿不准就实测；描述与实测不符**必须报**；不因清单没写就推断能力不存在 |
| `read` 读二进制 | 说「`read_text` 只处理文本」（工具名已不存在），不说该用什么 | 图片指向 `read_image` + `image_info`；其它给 shell 侧手段 |
| `edit` 未命中 | 只说「找不到，请先用 `read_text` 确认原文」 | 报近似行号 + 缩进差异（两边空格数）+ 全角/半角差异提示 |
| 禁用 shell 文案 | 本地拒绝也提「跨主机传文件用 SFTP」 | 按场景拆分，远程才提 |
| `sftp_hosts` / ENV.md | 推荐 `read_text / write_text / edit_text` | `read / read_many / write / edit` |

## 能力开关可见

设置页勾选后原本只有一句「已保存；重载后生效」，无法确认结果。新增**生效快照**：

每次 `apply` 把实际注册结果写进 `effective.json`，并打一行日志摘要。关键是
`on`（闸门打开）与 `active`（真的注册出工具）**并排**：

```json
"sftp": { "on": true, "active": false, "tools": [] }
```

这一行就是「打开了但没生效」。

> 该文件是运行时观测产物，已加入 `.gitignore`；路径在每次求值时读取
> `DSH_AGENTKIT_STATE_DIR`，测试不会污染真实快照。

## 效率：并行不再被压制

persona 第 11 条原写「**除非确有并行收益，优先单会话串行**」——默认值是串行，
模型面对不确定时必然选串行，可并行的任务也被串起来做。

改为：互不依赖、写盘不重叠时用 `subagent` 并行派发，不要自己串；只有真正有依赖
或写同一批文件才串行。

## 设置页精简

能力开关、镜像、代理、预设管理、新建预设原本全部平铺，首屏被十多个技术字段淹没。
现在镜像与外网代理**折叠**（收起时显示当前值摘要），能力开关与预设选择留在首屏。

## 验证

**24 个测试文件、225 项断言通过。** 新增：

| 测试 | 项数 | 覆盖 |
|---|---|---|
| `tool-lifecycle` | 8 | 自动登记 effect、全部回收、幂等、逆序、抛错隔离、卸载后可重新注册 |
| `gate-reconcile` | 10 | 只裁剪不新增、undefined 不裁剪、引擎 |
| `tasks-isolation` | 5 | 账本按会话隔离、缺 sessionId 安全降级 |
| `effective-snapshot` | 8 | on/active 不一致可见、写盘失败不打断主流程 |
| `edit-diagnose` | 7 | 缩进/全角/首行命中/完全找不到 |
| `binary-hint` | 4 | 图片指向 read_image、非图片给通用出路 |
| `settings-layout` | 7 | 真实渲染：四区块都在、默认收起、首屏更短 |
