# 通用 agent 工具集 v1.4.8

`@local/dsh-agentkit` —— 与翻译、模型无关的通用 agent 工具集，以 DSH 的 bundle + agent preset 形式分发。提供一个 `generic`（通用环境）预设，以及一组「把 Windows 上最容易出错的环节封进工具层」的能力。

## 这一版有什么

**编码 / 换行 / 字符集全兜底**
本地与 `代号:/远程` SFTP 读写都按原字符集编码写回，避免 GBK / UTF-8 混用导致的乱码；读文件返回探测到的字符集与换行风格。

**Shell 白名单**
禁用 Windows PowerShell 5.1 与 `cmd`，放行 `sh`（bash）与 `pwsh`（PowerShell 7，UTF-8）。理由：5.1 的管道编码和 `cmd` 的代码页是不可控变量。

**镜像与代理**
pip 走清华、npm 走 npmmirror、模型下载走 hf-mirror；直连慢或不通时自动注入代理。配置在设置页，不写进用户全局环境。

**工具面**

| 模块 | 内容 |
|---|---|
| 文件 | 读写、列目录、编码探测、大文件切分（`split`）、文件账本式任务面板（`tasks`） |
| 执行 | `sh` / `pwsh` / 通用 `run`、沙箱提权、环境探测 |
| 远程 | SFTP（含 Python sidecar）、远程检索 |
| 内容 | 文档处理、图像处理（含 `image_ops.py`） |
| 平台 | 技能加载、检索、委派、后台作业、交付卡片、预设管理 |

**按 preset 隔离**
所有工具注册在选中该 preset 的会话里；宿主行 `agentkit` 只承载设置页，不注册任何工具，不污染其它 preset / 会话，也不改变宿主默认行为。

## 安装

```bash
# 方式一：DSH 插件管理器
plugin_manager install_bundle <本目录 或 local-dsh-agentkit-1.4.8.tgz>

# 方式二：命令行
dsh plugin --profile <profile> install local-dsh-agentkit-1.4.8.tgz
```

装完**重启一次** DSH Desktop（新增 / 删除 JS 模块需要重启；只改 YAML 补丁会热重载）。

## 已知限制

- 面向 Windows 环境设计；shell 白名单规则会拦掉依赖 `cmd` / PowerShell 5.1 的既有脚本。
- 远程能力依赖 SFTP sidecar 的 Python 环境。
- 目标运行时为 DSH 0.2.1-rc.3，更早版本未验证。
